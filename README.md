# K230 钢珠位置接收与电机控制练习

本工程用于学习车载平衡滚球控制：K230 检测钢珠位置，STM32 接收位置数据，并通过电机驱动板改变轨道坡度。

目前完成了 **K230 串口数据转发**和**电机正反转测试**。STM32 尚未解析位置帧，也尚未实现钢珠位置 PID 控制；当前电机运动是固定时间的测试程序。

## 硬件与开发环境

| 项目 | 当前配置 |
| --- | --- |
| 主控 | STM32F103ZET6 |
| 视觉模块 | K230，运行现有钢珠检测程序 |
| 电机驱动板 | Emm42_V4.1 |
| 下载与调试 | PWLINK，Keil 选择 CMSIS-DAP Debugger，接口使用 SWD |
| 串口监视 | 额外的 DAPLink 串口功能 |
| 开发工具 | STM32CubeMX、Keil MDK，使用 STM32 HAL 库 |

## STM32 引脚连接

| STM32 引脚 | 配置 | 连接 / 用途 |
| --- | --- | --- |
| **PA10** | USART1 RX | 接 K230 的串口 TX，接收钢珠数据 |
| **PA2** | USART2 TX | 接 DAPLink 的串口 RX，用于电脑监视转发数据 |
| **PA6** | TIM3 CH1 PWM | 接电机驱动板 **STP**，输出步进脉冲 |
| **PA7** | GPIO 推挽输出 | 接电机驱动板 **DIR**，切换方向 |
| **PA13** | SWDIO | 接 PWLINK 的 SWDIO |
| **PA14** | SWCLK | 接 PWLINK 的 SWCLK |
| **GND** | 信号参考地 | K230、STM32 和 DAPLink 需共地；STM32 与电机驱动板信号侧也要有共同参考地 |

USART1 TX（PA9）和 USART2 RX（PA3）也已在 CubeMX 中配置，但当前测试主要使用上表的 PA10 和 PA2。PA7 上电初始化为低电平；高、低电平分别对应轨道升高或降低，需要根据实物接线确认。

### 电机驱动板的其他接线

驱动板接口标有 `V+`、`GND`、`COM`、`EN`、`STP` 和 `DIR`。其中 `V+` 与 `GND` 是驱动板电源接口，供电电压应根据实际驱动器及电源确认，**不能把电机电源的 V+ 当作 STM32 的 3.3 V**。

当前实测：用户将 **COM 和 EN 接在驱动板的 3.3 V**，STP 接 PA6、DIR 接 PA7，已经观察到轨道在两个方向运动。**这只是当前实测接法；V4.1 的 COM 电气规格和 EN 有效电平尚未通过对应说明书核实。**EN 固定接线时，程序不能通过 GPIO 单独控制使能。

## 当前串口测试

```text
K230 TX → STM32 PA10（USART1 RX）
            ↓ 接收中断和缓冲区
STM32 PA2（USART2 TX）→ DAPLink RX → 电脑串口助手
```

- USART1 和 USART2 当前均设置为 **115200、8 位数据、无校验、1 位停止位（8N1）**。
- 串口助手可以选择 HEX 显示，观察到例如 `AA 8A 01 03 8E` 的字节流。
- K230 现有备份代码使用固定五字节帧：`[AA][x低字节][x高字节][flag][checksum]`，其中 x 是像素坐标。
- 当前 STM32 程序只是逐字节接收并转发，**还没有解析帧、校验数据或计算物理位置**。串口助手把几帧显示在一行，不代表协议帧长度改变。
- 接收使用 USART1 中断和环形缓冲区；`rx_overflow` 记录软件缓冲区满时丢弃的字节数。

## 当前电机测试

TIM3 CH1（PA6）配置为 PWM：定时器时钟 8 MHz、PSC=79、ARR=999、Pulse=500，理论输出约 **100 Hz、50% 占空比**。

程序进入主循环后重复执行：

1. PA7 输出低电平，启动 STEP 脉冲约 2 秒，再停止。
2. PA7 输出高电平，启动 STEP 脉冲约 2 秒，再停止。
3. 两次运行之间留有短暂间隔，随后重复。

用户已上板观察到轨道往返移动。程序**上电或复位后会自动重复运行**，测试前应确认轨道有足够行程，避免撞到机械端点。固定两秒不保证准确的位置，也不代表已经实现位置闭环。

当前使用 `HAL_Delay()` 等待电机运动。等待期间串口接收中断仍可能运行，但主循环不能及时转发数据，缓冲区可能溢出；同时处理视觉数据和电机时需要改进这一点。

## 打开和构建

1. 使用 CubeMX 打开 [study.ioc](study.ioc) 查看或修改外设配置。
2. 使用 Keil 打开 [MDK-ARM/study.uvprojx](MDK-ARM/study.uvprojx)。
3. 编译工程，通过 PWLINK 下载到 STM32。
4. 调试器使用 CMSIS-DAP、SWD。烧录前确认测试机构状态，因为程序运行后会自动驱动电机往返。

主要用户代码位于 [Core/Src/main.c](Core/Src/main.c)，修改时优先写在 CubeMX 的 `USER CODE` 区域中。
